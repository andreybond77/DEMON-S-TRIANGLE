# 🔺 Demon's Triangle

Браузерная логическая игра на SVG. Крутите треугольники, собирайте одинаковые цифры в центре и получайте множители.

**[🎮 Играть в демо](https://andreybond77.github.io/demons-triangle/)** · **[📂 Исходный код](https://github.com/andreybond77/demons-triangle)**

---

## ✨ Возможности

- **Геометрия на SVG:** Поле состоит из 4 подтреугольников, каждый разбит на 3 части через **инцентр** (пересечение биссектрис).
- **76 уникальных орбит:** Канонические перестановки {1..6}³ без повторов.
- **Два типа выигрыша:**
  - 🎉 Автоматический — три одинаковые цифры в центре → множитель `t+1`.
  - 🖐 Ручной — клик по центру (1 раз за раунд) → ×1.
- **Поворот колец:** Внешние треугольники крутят цифры на 120° (бесплатно).
- **Визуальные эффекты:**
  - Частицы на SVG (искры).
  - Анимация «струйки» — перетекание выигрыша между ромбами (градиент + `stroke-dashoffset`).
  - Пульсация центрального треугольника.
  - Подсветка выигрышных точек.
- **Интерактив:** SVG-ползунок ставки, анимированный счётчик депозита.
- **Звук:** Web Audio API (синтез, без внешних файлов).
- **Адаптивность:** от 320px до 900px.

## 🛠 Технологии

| Слой | Что использовано |
|------|------------------|
| Рендеринг | SVG (полигоны, линии, текст, градиенты) |
| Логика | Чистый JavaScript (ES6+) |
| Геометрия | Инцентр, центроид, биссектрисы, поворот на 120° |
| Звук | Web Audio API |
| Анимации | CSS + `requestAnimationFrame` |

**Без зависимостей.** Никаких фреймворков и сборщиков.
